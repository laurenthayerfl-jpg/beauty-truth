# The Beauty Truth Website

## Overview

The production website is [thebeautytruth.com](https://thebeautytruth.com) and runs on WordPress.

The website is the education and organic-search arm of The Beauty Truth. Its purpose is to build trust, authority, and an audience around evidence-informed skincare education.

The website should eventually support the Beauty Truth app by attracting consumers who want help understanding skincare products, ingredients, and routines. It must also remain useful independently of the future app.

## Production Safety

Production WordPress access has **not** been provided. Codex must not attempt to modify the live website.

## Editorial and SEO Standards

- SEO work should prioritize genuinely useful content and topical authority rather than mass-produced AI content.
- Scientific and skincare claims require verification before publication.
- Human review is required before anything is published.

## Workspace Directories

- `seo/` is reserved for future SEO planning and analysis.
- `content/` is reserved for future website content work.
- `research/` is reserved for future supporting research.

The editorial workflow uses four specialized Codex agents for SEO research, scientific evidence research, drafting, and independent claims review. The main Codex task coordinates them only when Lauren explicitly requests the pipeline. See [The Beauty Truth Content Pipeline](content-pipeline.md) for the operating procedure and human-approval gate.
